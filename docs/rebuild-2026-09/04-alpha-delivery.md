## 本轮落地内容

- 多目标、关键要素/里程碑/子目标、任务、目标地图与大纲；手动编辑、节点重新归属与无环校验。
- 今日、周计划、跨周改期、四象限和未知优先级区；计划日与硬截止分离；所有目标共享每日容量及弹性比例。

- 真实通义智能体适配：文本/选中文件 → 有界上下文 → 单一关键问题或结构化草案 → 来源查看 → 手改/按项排除 → 当前版本确认 → 原子应用/撤销。

- 实时语音采集/PCM 重采样/ASR WebSocket 代码、临时字幕/稳定文本、停止/取消、授权撤回；文字等价入口。系统短播报明确不是云 TTS。
- SQLite 桌面存储、IndexedDB 网页存储、增量事务、版本冲突、持久撤销、操作幂等、导入预览/JSON 导出、独立示例空间。
- 雾白/矿物绿 UI、深色模式、响应式窄窗口降级、键盘搜索/助手、减少动效；地图与助手按需加载。

## 相对规划的实现决定

1. 桌面壳本轮保留并加固 Electron，而不是声称已迁移 Tauri。这样复用既有 Windows 安装流程，并把本地网关内置；Tauri/WebView2 的包体与麦克风性能对照仍是待办。SQLite 通过异步 IPC 暴露；实际数据库使用主进程 `node:sqlite` 同步事务，不虚称已移入 Worker。
2. 桌面使用受控 `app://master` 同源静态资源、隔离 preload、关闭 Node 集成及页面跳转限制。网关监听本机随机端口，使用每次启动的随机令牌；不把 `Origin: null` 无鉴权放开。依据 [Electron protocol 文档](https://www.electronjs.org/docs/latest/api/protocol) 实现路径边界与资源访问。
3. Web 开发网关默认 4318，来源白名单/Host 校验、限频/限并发/超时/取消。请求幂等仅在网关保留窗口内，不承诺服务器重启后继续恢复旧推理。
4. AI 最终草案完整验证后显示；当前不是 SSE 逐 token/partial-object 展示。语音字幕是流式。对话上下文只读，模型没有直接写库、Shell 或任意文件工具。
5. 桌面密钥位于用户数据目录 `master-ai.env`，是本机明文配置而非已加密的系统凭证库。它不进入前端包、计划备份或日志；后续商业发布需升级安全存储。
6. 首次已报告完成项默认不勾选，用户另外核实。历史完成缺日期就保留未知，不把确认日当完成日。片段引用存在不证明现实工作已完成。
